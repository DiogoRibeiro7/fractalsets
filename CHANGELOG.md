# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2025-10-12

### Added

- Initial release of FractalSets package
- Mandelbrot set generator with Numba optimization
- Julia set generator with multiple presets
- High-performance parallel computation
- Smooth coloring algorithm
- Multiple built-in colormaps (fire, ice, psychedelic)
- Export functionality for high-resolution images
- Fractal gallery with famous configurations
- Deep zoom capabilities
- Mathematical utilities (fractal dimension, area estimation)
- Comprehensive test suite
- GitHub Actions CI/CD workflows
- Monthly maintenance reminder workflow

### Core Features

- `MandelbrotGenerator` - Generate Mandelbrot sets
- `JuliaGenerator` - Generate Julia sets with custom constants
- `FractalVisualizer` - Visualization with matplotlib
- `FractalGallery` - Pre-configured fractal collection
- Export to PNG with custom DPI and colormaps

### Documentation

- Complete README with examples
- Inline documentation for all public APIs
- CITATION.cff for academic citation
- MIT License
